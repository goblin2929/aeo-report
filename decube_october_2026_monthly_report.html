Method

Search Console API for https://www.decube.io/, pulled week by week so no week is truncated by a row limit: 142,905 query rows plus 82,836 query×page rows. Brand queries, Indonesian traffic and adult/piracy spam are removed before anything is counted; the spam pattern is the one used in the monthly report plus the variants added in September. Automated queries are also removed: a query with no click in the 90 days, at least 3,000 impressions, and 80% or more of them inside its three busiest weeks. Six met that rule: “data lineage tracking” (123,132), “data catalog platforms” (96,130), “%python web framework” (34,488), “data quality management” (8,773), “run quarterly reports on the mpi to analyze the quality o...” (7,144), “quality control management system data model entities sch...” (5,899). Each query is tested against the L2 rows in order and the first match wins, so the specific always beats the general. Position is weighted by impressions. Refreshed and new tags come from the Content Delivery Tracker (Published rows for August, September and October). Search Console withholds rare queries, so per-query totals sit below the site totals in the interface; both halves are withheld the same way, so the comparison holds. AI search: WorkDuo Data API daily metrics and Core API citations (own URLs, deduplicated for scheme, www and trailing slash), the Search Console generative AI features export of 2 Nov, and GA4 sessions from AI platform sources.
